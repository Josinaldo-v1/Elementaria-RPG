# 🌀 Sabedoria

> [!abstract] Elemento: [[Magia]]
> Modificador ligado ao elemento **Magia**. Tudo que se testa em Elementaria é um modificador (ver [[Tipos de Teste]]).

## Dano elemental
**Danos em Magia Pura (somatório ao dado)** — a quantidade exata do modificador de Sabedoria é adicionada como dano extra aos dados de dano do elemento [[Magia]].

## Perícias (testes)
| Perícia | Rolagem |
|---|---|
| [[Arcanismo]] | Somatório |
| [[Intuição]] | Xd20 |
| [[Resistência Psicológica]] | Xd20 |
| [[Memória]] | Somatório |

## Testes forçados
Testes forçados deste modificador gastam pontos de **Ether** (ver [[Testes Forçados]]).

## Dados por valor
Nos testes **Xd20**: dados = 1 + (modificador ÷ 4, arredondado para baixo).
