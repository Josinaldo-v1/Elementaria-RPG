# ⚜️ Ether e Plasma

**Pontos alteradores de realidade** — os "forçadores de teste".

Cada jogador possui uma quantia de pontos de **Ether** ou **Plasma** que permitem forçar testes. Os pontos só são recarregados por meios específicos no sistema.

| Ether | Plasma |
|---|---|
| [[Medo]] | [[Agilidade]] |
| [[Energia]] | [[Carisma]] |
| [[Força]] | [[Precisão]] |
| [[Inteligência]] | [[Fé]] |
| [[Sabedoria]] | [[Vigor]] |
| [[Constituição]] | [[Vitalidade]] |

Regras completas em [[Testes Forçados]].
